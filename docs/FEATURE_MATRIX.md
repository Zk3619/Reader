## 11. 优先级定义

| 级别 | 含义 |
|------|------|
| **P0** | 无此无法自称「Legado 书源兼容」：编辑、调试 |
| **P1** | 日常阅读闭环：RSS、书签、记录、换源、缓存、目录更新 |
| **P2** | 体验对齐 Max：TTS、校源、多格式、调试台 |
| **P3** | Max 增强或小众：Web 服务、漫画、热力图 |
| **P4** | 独立产品方向：云端账号 |
