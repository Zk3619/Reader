# 顶栏

始终固定在顶部显示，并根据窗口大小自动调整。

## 书架

```
|-------------------------------------------------------|
|logo|阅读|   |书架|分组名|  |收藏|搜索|更多|最小化|最大化|关闭|    // 此处分组名右侧的内容至少以 icon 展示
|-------------------------------------------------------|
```

程序启动后默认显示书架页，因此需要确保宽屏下最小宽度能完整显示上述内容。若空间足够，可以为收藏、搜索、更多添加文字描述。

```
|-------------------------------|
|书架|分组名|        |收藏|搜索|更多|
|-------------------------------|
```

移动端不再显示右侧最小化、最大化和关闭的图标；窄屏下不再显示左侧的 logo 及程序名，且此时分组名右侧要显示的内容仅以图标形式显示，并根据大小选择性截断分组名（以 ... 作为无法显示的剩余内容展示）。

考虑 Web 端兼容，不再显示右侧最小化、最大化和关闭的图标，根据浏览器窗口大小自动调整显示内容。

良好的宽窄屏处理是完美的响应式设计的基础。这里没有使用桌面或移动这样的描述，是因为我将手机横屏、平板设计为以类桌面的效果展示界面。但也要正确处理移动端端的特殊性：不再显示右侧最小化、最大化和关闭的图标。Web端兼容以手机横屏/平板的设计为主。

## 书架

位于主要内容区域

### 分组

- 应用启动时书架页面默认显示为分组
- 分组有三种显示形式：
  - 导航栏分组名改为下拉框，用户下拉选择具体分组，主要内容区域显示当前分组的书籍，仅宽屏
  - 标签，本意是将导航栏分组名改为可以横向滚动的子栏（使用 Navigation Menu 或 Menubar），如果无法实现这种嵌套关系，可以在主要内容区域顶部新增它作为分组标签，其下方的内容区域显示当前分组的书籍，仅窄屏
  - 常规，直接在主要内容区域显示，分为分组列表和分组网格，但都使用Grid布局，通用

#### 分组列表

分组列表是一列的Grid，分两种具体布局，常规列表和紧凑列表

```
// 常规列表
|         |       |
| 分组封面 | 分组名 |
|         |       |
        
// 紧凑列表
| 分组封面 | 分组名 |
```

#### 分组网格

分组网格始终占满主要内容区域，最少二列，最多六列，根据主要内容区域大小自动缩放内部组件大小

```
// 一个单元格的内容：封面图和书名
|         |
|   封面   |
|         |
|---------| // 此处作为间距而不是分割线
|   书名   |
```
